When a project calls for native, deeper system access, or performance, I work with [`Rust`](https://www.rust-lang.org/), [`Tauri`](https://tauri.app/), [`C++`](https://isocpp.org/), or [`JUCE`](https://juce.com/).

I work remotely from my home on a lake in [`Texas`](https://en.wikipedia.org/wiki/Texas) for a large [`NYC`](https://en.wikipedia.org/wiki/New_York_City)-based [`direct-to-consumer`](https://en.wikipedia.org/wiki/Direct-to-consumer) conglomerate, building [`headless`](https://en.wikipedia.org/wiki/Headless_commerce) commerce systems with [`TypeScript`](https://www.typescriptlang.org/), [`React Router`](https://reactrouter.com/), and [`Shopify`](https://shopify.dev/docs/storefronts/headless) across its portfolio of brands.

Technology, music, and motor vehicles are my passions. In software, that curiosity draws me to local and cloud AI, media tooling, private peer-to-peer systems, and thoughtfully designed local-first products.
